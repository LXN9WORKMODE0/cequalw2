# 03 文献综述

本页回答什么问题：学术文献和官方资料怎样看待 CE-QUAL-W2 及同类 laterally averaged 模型的能力边界，这些结论对你当前这个中间水库意味着什么。

## 综述结论

文献的共识并不复杂：

- laterally averaged 模型非常适合长、窄、分层明显、横向变化次要的水体。

- 一旦进入库河过渡带、变动回水区、结构物近区、支流汇入口或强横向不均匀区域，误差往往来自模型假设本身，而不是只靠调一个参数就能解决。

- 对单个中间水库而言，最有性价比的工作通常不是先上全域 3D，而是先把边界、结构物切换、局部耦合和垂向闭合做好。

## 对你当前问题最有价值的三条文献结论

### 1. 适用范围本来就以“长窄、横向较均匀”为前提

`L1`、`L3`、`L4` 都在不同程度上强调，W2 的典型适用对象是 laterally averaged 可以近似成立的系统。

这意味着：

- 你的中间水库如果整体仍是狭长型，那么 W2 仍然是合理主模型。

- 但靠近回水末端、坝前、结构物或支流入汇处时，误差会明显上升。

### 2. 耦合区和结构物切换最值得优先补强

`L5` 的价值很高，因为它给出的不是抽象批评，而是非常工程化的方向：

- 不必全域重耦合。

- 重点在敏感耦合区做迭代。

- 把自由/淹没切换从硬阈值改成连续过渡。

这和你当前代码里 `hydroinout.F90`、`gate-spill-pipe.f90` 暴露出来的问题高度对口。

### 3. 边界质量往往比库内参数更先决定上限

`L7` 给出的工程启发很直接：如果来流、尾水位、结构物运行和分层边界表达不够细，库内再怎么调混合参数也只能局部补救。

对你这个单个中间水库，边界优先级至少不低于垂向闭合。

## 当前文献对方法选择的共同建议

- 只关心水位过程和调度响应：1D Saint-Venant 更高效。

- 同时关心水位、热分层和取水层位：W2 仍然是合理主模型。

- 现场横向不均匀、局部回流或复杂密度流很强：考虑局部 2D/3D 作为校核或嵌套，而不是先把整库全部替换。

## 当前文献还没有替你解决的部分

- 文献能说明“哪类短板是结构性的”，但不能替代你这个库区的边界重建和实测校核。

- 文献能说明“局部耦合和边界补强值得做”，但具体怎么写进 `w2_main.f90`、`hydroinout.F90` 和 `gate-spill-pipe.f90`，还得结合当前源码来定。

具体链接、使用方式和结论映射见 [references.md](./references.md)。
