# W2 结构性局限最小实验集
本页回答什么问题：在尽量剥离输入总量误差之后，当前 W2 case 是否还能自然模拟 `SEG 2` 到 `SEG 222` 的真实水面线，以及误差更像输入闭合问题还是结构性水动力问题。
Updated: 2026-04-16

## 1. 为什么要单独做这组实验

- 前面的多因素矩阵和双站点分析已经说明：只看坝前 `SEG 222` 会把“总量偏差”和“天然水面线偏差”混在一起。
- 这组实验的目的不是找最优校准参数，而是把问题剥开：
- 第一层，尽量用更物理的方式修正输入总量偏差，不依赖 distributed。
- 第二层，在这个基础上再动库尾过渡带几何/糙率，看天然水面线能不能一起被做对。
- 如果第一层修好了整体量级，第二层仍做不好 `SEG 2-SEG 222` 的坡降和 `SEG 2` 的持续成水，那么就更能说明问题来自 W2 当前结构，而不只是输入数据不全。

## 2. 最小实验集设计

- `B0`：当前实际 case，保留现有 distributed，作为工程现状参考。
- `B1`：全部 distributed 关闭，作为无补偿底板。
- `Q120/Q150/Q200`：在 `B1` 基础上，仅把 5 条无监测支流基础 `QIN` 同比放大 `1.2/1.5/2.0`，不动几何，不动 distributed。
- 从这三组里，按 `|common-mode bias|` 最小选出最佳输入 case。结果表明 `Q200` 最接近“把输入总量偏差尽量剥掉”的目标。
- `Q200_G5`：在 `Q200` 基础上，只对 `SEG 2-58` 施加 `MANN x1.2 + AREA x0.9`。
- `Q200_G6`：在 `Q200` 基础上，只对 `SEG 2-122` 施加 `MANN x1.2 + AREA x0.9`。
- `D7/I3`：不再作为“最优答案”，只作为人工补总量参考，用来比较“总量补近”与“天然水面线做对”是不是一回事。

## 3. 关键结果

- `Q200` 已经把输入轴推得很强：`common-mode = -1.530611 m`，明显优于 `B1 = -5.690098 m`，也优于 `B0 = -2.762622 m`。
- 但 `Q200` 的 `differential-mode = -4.583 m`，不仅没有改善，反而比 `B0 = -4.159333 m` 更差。
- `Q200` 的 `SEG 2` 首次有效水面时间提前到了 `2021-08-26 07:55`，比 `B0` 更早，但仍远晚于研究口径要求的“始终有水”。
- 到 `2021-09-10`，`Q200` 的模拟两点水面差只有 `1.397 m`，而实测是 `7.83 m`。也就是说，即使把输入总量往回拉，天然坡降仍然塌得很厉害。
- `Q200_G5/Q200_G6` 把 `SEG 2` 提前成水到了 `2021-08-24` 左右，但同时把 `common-mode` 推成了强正偏差，坝前 RMSE 直接恶化到 `10-11 m` 量级，而且 `2021-09-10` 的两点差反而只剩 `0.7 m` 左右。
- `D7` 这类人工 distributed 参考说明：总量补偿可以把坝前压得很近，但 `differential-mode` 仍有 `-4.418714 m`，并没有自然恢复真实水面线。
- `I3` 是当前对照里最接近“同时顾及两边”的参考之一，但它依然只有 `SEG 2` RMSE `3.242646 m`、`differential-mode = -3.503211 m`，而且 `SEG 2` 依然不是从窗口起始时刻就处于连续有水状态。

## 4. 对结构性局限的含义

- 这组实验最重要的发现是：把输入总量偏差剥离掉以后，问题并没有自然消失。
- 更具体地说，当前 W2 case 的误差不是“因为支流总量偏小，所以只要把总量补够就会自动恢复真实水面线”。
- 相反，实验表明输入轴和结构轴是分开的：
- 输入轴主要决定两站整体量级，也就是 `common-mode`。
- 结构轴主要决定 `SEG 2` 是否能稳定参与演化，以及 `SEG 2-SEG 222` 的天然坡降是否会过快塌缩。
- 因此，本 case 当前最稳妥的判断仍然是：
- 输入不完整当然是误差源。
- 但把这部分误差尽量剥离后，W2 当前这套活动段机制与分裂推进水动力逻辑，仍然存在明显结构性局限。

## 5. 这组实验支持了哪些更具体的判断

- `SEG 2` 的问题不只是水位偏低，而是它在当前计算逻辑里没有被稳定地当作始终存在的天然河流段来处理。
- 只增加支流总量，最多能让 `SEG 2` 更早成水，却不能让它从一开始就稳定成水。
- 只调库尾过渡带糙率/面积，最多能改动局部响应，却不能同时维持合理的整体水位量级和真实纵向坡降。
- `distributed` 更像总量补偿，不是天然水面线修正器。
- 这意味着后续如果继续研究源码改造，优先级应继续放在 `CUS/JB` 活动段机制、自由液面与流速的分裂推进、以及库尾天然河流态与回水态的切换处理上。
