# V35 Multi-Station Waterline Validation

本页回答 V34 的路线 A 是否获得了有效物理约束，以及这些约束支持或否定哪一种下一步重构。

Updated: 2026-07-19

## 1. 输入与处理链

- 来源：2021/2023 两个库区水面线工作簿，以及转换后的 12 个逐时 NPT。
- 分析窗口：JDAY 44430.0–44436.5，与 V33 extended 基线一致，共 157 个逐时观测点。
- 模型基线：`redistribute_bht_a00_case`，物理状态与 V33/V34 起点一致。
- 处理：对齐 XLD、SS、HH、SLB、YMT、SJ、BHT 观测与 `wl.csv`；同时计算相邻站水头差和对 BHT 物理入流的 stage–Q slope。
- 状态变化：不改模型输入和水动力状态，只生成只读验证结果。
- 输出：`analysis/verification/v35_multistation_waterline/`。

## 2. 输入质量门禁

12 个 NPT 的格式、8760 点时间轴、单调 JDAY、数值范围全部通过；10 个内部站年度处理记录与 gap sidecar 完全对账。2021 XLD/BHT 与案例端点文件逐字节一致。

本次窗口内五个新增站均有 157 个原始有效点，没有任何清洗或插值。使用原工作簿再次逐点比较，五站合计 785 个值在保留 0.01 m 后无差异。因此本窗口不受全年自动清洗规则影响。

全年文件仍保留两项限制：

1. 2021/2023 内部站分别有 293/885 个插值点，最长连续插值 68/74 h；这些区间不能未经复核直接进入率定目标。
2. 原工作簿没有明确写出各站的统一高程基准。当前结果暂按同一基准解释；这是尚未从元数据独立确认的前提。

## 3. 测站映射

当前采用转换包中的最近中心映射：XLD/SS/HH/SLB/YMT/SJ/BHT 对应 segment 222/215/168/116/57/26/2。

XLD 的 0 km 究竟代表 segment 222 下游边界还是既有比较中的 segment 222 中心，会使 SS 改映射到 segment 214；其余内部站的 segment 不变。SS 两种映射的 bias 只差 `0.000077 m`、RMSE 只差 `0.000016 m`，不影响空间结论。

## 6. 对现有重构边界的反证

新增站不位于 segment 3:6，所以仍不能识别 V33 三个内部界面的独立阻力；它反而表明继续只在 segment 2:6 内调阻力会错过主要空间缺口。

直接把 V27 的“单总 storage + 单线性 profile”扩展到 BHT–YMT 也不可行。即使使用观测 BHT/YMT 作为完美端点，按里程线性插值得到的 SJ 水位仍比实测平均高 `5.137 m`，RMSE `5.211 m`。这不是边界误差，而是单线性 profile 表达能力不足。

## 7. 审视结论

路线 A 有帮助，并解除“误差空间位置未知”的阻塞，但没有授权 V33 的逐段局部阻力激活。

- 拒绝：继续把 segment 2:6 的三个局部 Manning target 直接激活。
- 拒绝：把当前单线性 profile 原样扩展到 segment 57。
- 支持：以 SJ（segment 26）和 YMT（segment 57）作为宏观控制断面，先设计分区/分段 profile；至少需要 BHT–SJ 与 SJ–YMT 两个独立状态区，且每区必须有独占 volume 和守恒通量。
- 约束：若 ownership 扩展越过 segment 28，将包含 BR2 在主干 segment 28 的汇入点；支流流量、温度和组分必须进入新控制体，不能只改 `TAIL_FIXED_MIN_NSEG`。

下一步先做 V36 observation-anchored macro-domain preflight：比较“止于 segment 28 前”和“跨过 segment 28、以 YMT 为边界”的状态/源汇链，建立无重叠 ownership 和最小守恒方程，再决定是否值得运行结构实验。
