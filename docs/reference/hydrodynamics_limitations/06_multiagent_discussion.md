# 06 多 Agent 讨论纪要

本页回答什么问题：这次专题研究里不同 agent 分别贡献了什么、有哪些共识和分歧、最终为什么采用现在这套口径。

## 分工

- `Hegel`：负责本地资料落点和源码证据，重点回答“专题目录应该放哪里”和“哪些 Fortran 文件最能支撑问题判断”。

- `Pasteur`：负责文献综述，重点回答“文献如何定义 W2 及同类模型的能力边界”和“单个中间水库最值得优先补强什么”。

- `Descartes`：负责模型比较，重点回答“1D Saint-Venant、laterally averaged W2、2D/3D 更高维模型在这个场景下怎么选”和“为什么会表现成偏快和偏硬”。

- 主线程：统一口径、筛掉和当前任务无关的扩展点，把结论压缩成能直接服务后续源码改造的档案。

## 主要共识

1. 这不是“横向平均完全错了”的问题，而是 laterally averaged 框架在变动回水切换场景里的边界和耦合短板被放大。

2. 当前最优先补强的不是全域 3D，而是边界、结构物切换、局部迭代和垂向闭合。

3. 纵向偏快主要与分裂推进、边界传播和结构物流量硬切换有关。

4. 垂向偏硬主要与诊断式 `W`、`AZ` 闭合上下限和 `LAYERADDSUB` 阈值式调整有关。

5. 四库串联虽然是背景，但当前这个专题应该聚焦单个中间水库，否则问题会被系统级耦合讨论稀释。

## 有过分歧但最终收敛的点

### 1. 要不要把模型比较放在主线中心

- `Descartes` 给出了较完整的 1D / W2 / 2D-3D 对比。

- 最终决定：保留比较，但不让它抢走主线。当前专题的核心不是“换模型选型”，而是“为什么现有 W2 在这个库上不够准，以及还能怎么优化”。

### 2. 要不要把横向平均作为首要矛盾

- 多个方向都承认 laterally averaged 假设会损失横向信息。

- 最终决定：把它作为结构性背景限制，而不是当前首要矛盾。原因是你已经明确说明横向平均并不是当前最痛的部分。

### 3. 优化优先级先放边界还是先放主循环

- `Pasteur` 更强调边界质量和结构物切换。

- 本地源码分析更强调 `w2_main.f90` 的分裂推进和 `QC` 后校正。

- 最终决定：把两者合并，优先级顺序定为先收紧主循环耦合，再处理结构物与边界，因为它们本来就是同一条机理链上的前后两环。

## 最终采纳的口径

- 主判断：W2 是合理主框架，但当前工况踩中了它在变动回水区的结构性短板。

- 主症状：纵向前沿推进偏快、垂向响应偏硬。

- 主机理：分裂推进、边界和结构物切换过硬、垂向闭合偏刚。

- 主路线：`P1` 内迭代，`P2` 结构物平滑切换，`P3` 边界松弛，`P4` 垂向混合和层调整迟滞，`P5` 网格和时间步加密。

## 这次多 Agent 讨论留下来的额外提醒

- 如果后续发现某一段河库过渡带存在非常强的横向回流或局部绕流，仍然应该考虑局部 2D/3D 校核，而不是死守 laterally averaged 单模型。

- 如果后续实测表明边界数据本身波动很大或缺测严重，应该先修边界重建，再评价源码改造效果。

- 如果主循环改造后纵向偏快仍然显著，就要重新检查储量曲线、网格和局部几何表达，而不能只盯着求解器。

## 这份纪要的用途

- 用来说明结论不是单点直觉，而是源码、文献和模型比较三条线汇合后的判断。

- 用来给后续继续加 agent 或继续扩展专题时保留上下文。
