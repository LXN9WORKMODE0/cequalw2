# V34 Physical-Constraint Inventory

本页回答 V33 之后的一个阻塞检查：仓库中是否已经存在足够的中间河段观测、独立几何证据、局部阻力资料或外部一维模型，使 segment 2:6 的局部闭合可以在不新增物理假设的情况下继续施工？

Updated: 2026-07-16

## 1. 审计范围与方法

本次只审计 Git 跟踪的基线输入、验证副本、分析脚本、历史实验记录和文件历史，不把 `.runs` 中的模型输出当成独立观测。

- 输入：`cases/xld_2021_base`、`analysis/verification`、现有专题文档和 Git history。
- 处理：按文件名与内容检索观测序列，按 SHA-256 去重；比较 8 套 bathymetry 的头部元数据、`DLX/ELWS/MANN/LAYER`；检索常见 HEC-RAS、MIKE、Delft3D/DFLOW-FM 等一维模型扩展名。
- 状态：不改动模型、输入或运行产物。
- 输出：只记录“仓库内已有证据能证明什么、不能证明什么”。
- 上下游影响：无。

## 2. 水位观测盘点

Git 中共有 12 个名称带 `obs` 的时序文件，但 SHA-256 只有两个唯一内容：

- `el_obs2021.npt`：1 个基线文件及 5 个验证 case 的逐字节副本；
- `el_obs_upstream.npt`：1 个基线文件及 5 个验证 case 的逐字节副本。

当前项目约定把两者分别映射到 segment 222 坝前与 segment 2 上游，但文件头只有通用的 `eleobs / JDAY / el_obs`，没有测站名称、链桩、高程基准或 segment 映射元数据。因此：

- 仓库中没有第三个独立水位测站；
- 没有 segment 3、4、5 或 6 的同步观测；
- 两端观测的空间映射仍依赖当前项目约定，不能从时序文件自身独立复核。

## 3. Bathymetry 与阻力资料盘点

基线目录有 8 个 bathymetry CSV。其中 6 套含 268 个编号 segment，2 套含 284 个；它们共享相同的主干编号约定和 segment 2:6 `DLX` 序列，文件头都只说明 segment 222 宽度根据深泓线资料确定。

可见差异主要是：

- 垂向层厚为 `0.25 / 0.5 / 2 m` 的不同离散；
- 总 segment 数为 `268 / 284` 的不同支流配置；
- 初始 `ELWS` profile 不同；
- 统一 Manning 值为 `0.03` 或 `0.035`；
- 部分文件包含不同支流分区。

其中 `DIXING1157_XLD - 副本.csv` 与 `DIXING1157_XLD_0.25.csv` 的 SHA-256 完全相同。所有这些文件都在同一次旧工作区导入历史中出现；仓库没有附带 survey date、断面链桩/坐标、高程基准、segment 3:6 独立断面校核、局部结构物损失系数或分段糙率来源。

这不证明这些几何一定错误；它证明仓库内没有足够元数据把候选文件当成相互独立的物理验证资料。它们只能做输入敏感性方案，不能消除 V33 的几何—profile—阻力不可辨识性。

## 4. 外部模型与历史率定证据

- Git 跟踪文件中，常见 HEC-RAS、MIKE、Delft3D/DFLOW-FM 一维模型项目/网格/边界文件数量为 0。
- 旧基线的 `G5/G6` 实验曾对较长过渡带施加 `MANN x1.2 + AREA x0.9`；记录显示坝前 RMSE 恶化到 `10–11 m`，且目标水面差仍未同时闭合。

旧 `G5/G6` 结果来自 V24 之前的不同状态语义，只能作为“盲调面积与糙率已经出现过强副作用”的历史警示，不能替代 V33 基线上的新率定试验，也不能据此选定新的有效阻力。

## 5. 审视结论

仓库内现有资料不能自动解除 V33 的物理决策点。两端水位可以约束总水面差，却不能唯一分配 segment 2:6 各界面的坡降，更不能区分：

1. 线性 stage profile 错误；
2. 中间断面代表性错误；
3. 局部损失或分段糙率缺失；
4. 当前简化 Manning closure 本身不适合该非均匀回水段。

因此，不能把 V33 反推的 `n≈0.070/0.046/0.076` 自动写回模型。这些仍只是等效阻力需求。

## 6. 继续施工所需的最小输入

### 路线 A：物理数据优先

至少需要：

- 一个 segment 3:6 中间控制断面的同步水位序列，优先靠近 segment 4 或 5；
- 测站链桩/坐标、与模型 segment 的映射及统一高程基准；
- segment 2:6 断面与 reach length 的来源/日期校核；
- 已知结构物、滩槽变化和可接受的糙率先验范围。

一个中间水位站可约束 profile 形状，但若要分别识别三个内部界面的独立阻力，还需要更多空间观测或明确的正则化/分区假设。

### 路线 B：工程等效闭合

若不补数据，需要明确授权把阻力当作 endpoint-calibrated effective closure，并给定验收目标：端点 RMSE、流量响应 slope、两点 head，三者的优先级或联合权重，以及允许的参数范围。结果只能宣称为工程率定，不能宣称为实测 Manning 糙率。

### 路线 C：外部一维求解器

需要选择求解器、segment 2 与 segment 6 的耦合边界语义，以及是否交换温度/密度。仓库当前没有可直接接入的外部模型工程。

在用户选择 A/B/C 之前，V32/V33 是当前可验证、无未授权物理率定的结构基线。
